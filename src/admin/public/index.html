Панель
SitePanel — панель управления сайтами

Добавить сайт

Загрузите .zip архив или укажите Git-репозиторий. Если внутри есть package.json со скриптом start — сайт определится как Node.js-приложение и будет слушать process.env.PORT. Если внутри есть Dockerfile или docker-compose.yml — сайт запустится как Docker-проект (панель соберёт и поднимет контейнер; порт внутри контейнера берётся из EXPOSE/ports или задаётся в карточке сайта). Иначе — статический сайт.

Расписание бэкапов

Плановый бэкап пропускается, если каталог сайта пуст, а ошибка (например, мало места на диске) будет видна в карточке сайта. node_modules в бэкап не входит — зависимости ставятся заново при восстановлении.
